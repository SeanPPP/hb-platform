# Core contracts v3

这些 Port 是 iPad POS 各垂直切片与原生适配器的冻结边界。功能代理只能实现或消费接口；任何字段、状态迁移、数据库能力或敏感客显字段变更都必须由主代理评审并提升 `CORE_CONTRACT_VERSION`。

关键不变量：

- 金额仅用 AUD 整数分币。
- 交易行在加入购物车时冻结后端 `ReferenceCode` 与 `PriceSourceKind`；补传不得按当前目录推断。
- 现金订单必须在单一数据库事务中同时写订单、行、tender、审计与 outbox。
- `Unknown` 支付不得重新提交；只能查询并恢复同一 attempt。
- `Ambiguous` 打印和 `Unknown` 钱箱事件禁止自动重放。
- 外接客显 schema 为 strict，禁止设备/收银员 token、银行卡引用、顾客资料或设备授权。
- 远程历史只能使用可信收银会话门店，当前合同固定 WPF 首批 100 条且不开放退款、召回或远程重打。
- 特殊商品顺序是本机完整 permutation；iPad 离线只允许浏览与加购，不执行标记、下载或排序写入。
- 日结按门店、设备和营业日半开区间汇总，允许同一营业日保存多个不可变归档。
- 强制升级或门店关闭必须同时阻止离线现金新交易，但不得阻断补传、审计、支付恢复和支持导出。
- 后端未提供旧 scope 恢复凭据前，设备重注册必须先让旧 scope 未决购物车、支付、订单和审计归零；本地数据库永不删除。
