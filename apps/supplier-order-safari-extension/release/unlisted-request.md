# Unlisted App Distribution Request

HB Supplier Order is an internal business application for authorised Hot Bargain employees and purchasing personnel in Australia.

The application integrates with Safari to show authorised internal purchase and sales information while staff review products on supported supplier websites. It has no public registration, consumer onboarding, advertising, in-app purchases or public marketing campaign. Access requires an existing Hot Bargain account with appropriate organisational and store permissions.

The new App Store Connect record is initially configured for Public distribution because Apple requires the app to be submitted to App Review before an Unlisted request can be processed. The version uses Manual Release while the App Review and Unlisted requests are pending.

Unlisted distribution is requested so the application can be installed from a direct App Store link by the intended workforce without creating a publicly searchable App Store listing. App availability is restricted to Australia. The App Store version uses Manual Release and must not be publicly released if the Unlisted request has not been approved.

The iOS app is not made available as a Designed for iPhone/iPad app on Apple Silicon Mac.
