# 手持 POS 风格锚点

来源：`pos-mobile/anchors/prompt-set.md`。本文件是 `apps/pos-handheld` 的 UI 验收基线。

## 共享视觉约束

- 生产级原生移动 POS，高信息密度、低装饰、单列竖屏。
- 暖白背景 `#F4F1EA`、白色内容面、深蓝文字 `#10253A`、橙色主操作 `#E65A2F`。
- 绿色成功、蓝色信息、黄色警告、红色失败。
- 8px 间距节奏、48px 控件、小圆角和清晰分割线。
- 不使用渐变、玻璃效果、夸张卡片、底部 Tab、品牌 Logo 或水印。
- 不显示客显状态、客显设置或第二屏入口。

## 销售页

390×844 中文移动收银购物车：顶部显示门店、员工、网络、同步、扫码器和打印机状态；商品搜索；购物车商品；数量控制；订单汇总；底部固定橙色付款按钮。

## 付款页

延续销售页视觉系统：订单应付金额；现金、银行卡、礼品卡和分期；现金输入数字键盘；找零金额；底部确认收款按钮。

## 历史页

延续前序视觉系统：本地/远程切换、日期和状态筛选、订单搜索、订单号、时间、收银员、付款方式、同步状态和金额；采用列表进入详情的手机导航。

## 设置页

延续前序视觉系统：打印机与钱箱、扫码器、交易设置、员工与权限、语言、同步与离线、应用更新和设备信息；明确排除客显分区。
