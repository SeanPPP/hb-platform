# 销售明细 · 双标签三栏联动原型

布局：**左侧供应商 · 中间分店 · 右侧商品明细**，三个维度双向联动。两个标签分别为“澳洲供应商”和“HB 仓库 · 国内供应商”。

## 查看

在仓库根目录运行：

```sh
python3 -m http.server 4173 --bind 127.0.0.1 --directory docs/design/sales-detail-three-column-v2
```

- 澳洲标签：<http://127.0.0.1:4173/?kind=australia>
- 国内标签：<http://127.0.0.1:4173/?kind=china>

## 交互

- 默认优先展示“毛利指标”：三栏的名称后紧接毛利额、毛利率；切换“销售指标”恢复原销售字段优先顺序。两种视图都保留全部字段，不改变日期、关键字、反查条件或分页。
- 供应商与分店支持点击毛利额、毛利率表头排序；商品仍按原营业额排名，避免把当前页排序误当成全量排序。
- 点击供应商名称，联动分店与商品；点击分店，反查该分店的供应商金额、排名和占比，并筛选商品。
- 点击商品，反查对应供应商和各分店销售表现；再次点击取消。商品行支持键盘聚焦后按 Enter 选择。
- 三栏各自保留可切换候选，不会被自身选中项收窄；更换供应商时保留分店，供应商、分店、商品共同限定顶部汇总。
- 筛选条件标签可分别清除，其他条件保持不变；“清除全部”解除供应商、分店、商品和商品关键字。
- 商品关键字即时过滤名称、货号、条码、供应商名称和编码；多个词用空格分隔，必须全部匹配，不区分大小写。例如 `玛索 Notebook`、`HOT au200 woven`。
- 关键字只过滤右侧商品候选及顶部汇总，不直接收窄左侧和中间候选；点击搜索结果后才启用商品反查。修改关键字会解除旧商品选择，避免隐藏条件继续生效。清除关键字不会取消已选商品或分店。
- 输入纯空格不视为有效关键字；中文输入法组词期间不重绘输入框，确认候选后才过滤。
- 两个标签共享日期及同比设置；切换标签会清除供应商、分店、商品选择、关键字及分页；重复点击当前标签保留条件。
- 供应商名称/编码搜索仅过滤左侧候选。
- 三栏分别横向滚动并固定名称列和表头；标题右侧按钮可展开单栏，Esc 返回三栏。
- 拖动栏间分隔线调整比例；聚焦分隔线后按左右方向键可微调，双击恢复 28% / 27% / 45%。
- 快捷日期、按周/按日期同比、自动对比、商品分页和每页数量均可操作。

## 移动端字段对应

来源：`apps/mobile/src/modules/product-report/product-report-screen.tsx` 及 `api.ts`。

| 区域 | 字段 |
| --- | --- |
| 供应商 | 名称/编码、营业额、增长率、营业额占比、客单数、客单价、毛利额、毛利率；国内标签加中国货占比 |
| 分店 | 名称、营业额、增长率、客单数、客单价、毛利额、毛利率 |
| 商品 | 图片、货号/名称、金额、数量、均价、增长率、毛利额、毛利率 |

本期与同期上下排列。图片使用明确标注的商品示意图；货号/名称合并展示，增长率单独成列。默认毛利视图优先展示名称、毛利额与毛利率；其他字段通过栏内滚动或展开查看，也可切换销售视图。

### 毛利字段

按移动端 `SupplierReportRow`、`SupplierBranchBreakdownRow`、`ProductReportProductRow` 和 `ProductBranchBreakdownRow` 对齐四个字段：

| 移动端字段 | Web 原型显示 | 格式 |
| --- | --- | --- |
| `grossProfit` | 本期毛利额 | AUD，2 位小数 |
| `compareGrossProfit` | 同期毛利额 | AUD，2 位小数 |
| `grossMarginRate` | 本期毛利率 | 百分比，1 位小数 |
| `compareGrossMarginRate` | 同期毛利率 | 百分比，1 位小数 |

移动端接口使用 0–1 比率，展示时转为百分比；当前演示模型的 `margin / compareMargin` 已是 0–100 百分比，展示层不再次乘 100。毛利率按汇总毛利额 ÷ 汇总销售额计算，不平均各商品的毛利率。本页商品汇总同时展示本期和同期金额、毛利额、毛利率，口径对应移动端 `ProductPageSummaryCard`。

供应商占比沿用移动端：澳洲营业额占比的分母为全部供应商营业额；国内营业额占比的分母为国内供应商小计；中国货占比的分母为全部供应商营业额。每列表头提供分母提示。

选中分店后，占比的分子和分母均限定在该分店；选中商品后，分子为该商品的营业额，分母仍保留该分店（或未选分店时的全部分店）的供应商全量收入，不会因商品反查变成虚假的 100%。

顶部汇总统计所有已选条件的交集；右侧“本页商品汇总”统计当前候选页，选中商品后两处汇总可能不同，分别以标签标明。

“新增”表示同期为零、本期有销售。成本缺失时毛利额显示 `—`，毛利率明确提示“成本待补全”；真实零毛利显示 `$0.00`，真实零毛利率显示 `0.0%`。销售额为零导致的不可计算毛利率显示 `—`，提示“无销售 / 无同期销售”，不误报缺成本。自动对比关闭时同期及增长显示 `—`。

### 本轮验收结果

- 模型自动化测试 12 项通过，覆盖分店与商品反查、候选集保留、跨字段多词匹配、分店范围内的两类占比分母、全集/本页汇总、均价、同比、零基数和缺失成本。
- ego-browser 实际浏览器验证了分店反查、商品反查、交叉金额一致、切换与逐项清除、双标签、多词/编码/条码搜索、搜索空态、纯空格、中文组词事件、分页与键盘焦点以及自动对比。
- 毛利字段追加验证：三栏本期/同期毛利额及毛利率与事实模型逐项一致，视图切换保留反查条件，搜索/反查/分页同步重算毛利；缺成本、真实零值、无同期销售和关闭对比均检查。
- 在 1440px、1280px 和 390px 检查页面宽度，无页面级横向溢出；密集表格在自身容器内滚动。
- 独立 UI 只读审查完成，发现的纯空格提示问题已修正；额外穷举两个类别下的全部分店、商品及商品 + 分店组合，反查关系与候选集不变量通过。
