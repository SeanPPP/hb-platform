# 移动端省彩墨海报

新增第三种海报风格 `low-ink`，移动端文案为「省彩墨 / Low ink」。在商品的促销海报编辑页，通过「风格」选择；原有经典、现代及默认选择保留。

## 设计

- 纯白纸面、黑色大价格和正文；仅小促销标题与一段短线着色。
- 不使用满版背景、彩色价格、彩色边框或实心促销贴纸。
- 特价、多件价、清仓用少量红色；新品用少量绿色。四类都有文字标题，不依靠颜色区分。
- 数量、组合总价、单件价、混搭条件、有效期仍按每件商品的实际资料呈现。
- 原价与节省额只在有有效价格比较时出现。单价显示 EACH；多件总价明确标明数量。
- Logo 沿用批次开关，默认开启；关闭可进一步减少彩色图像内容。
- 覆盖 A4、A5、A6、A7，以及既有的 A4 拼版与裁切线。

## 样张

所有商品和价格均为测试演示资料，不是门店正式促销。

- `low-ink-posters-16-pages.pdf`：四种促销 × 四种纸张，共 16 页，使用实际后端 PDF 渲染器生成。
- `low-ink-A6-imposed.pdf`：四种 A6 海报拼成一张 A4，可查看排版和裁切线。
- `low-ink-preview.png`：上述 A4 拼版 PDF 的直接渲染预览。

打印 PDF 时选择实际尺寸 / 100%。本地样张与代码验证不代表已发布到线上或完成实体打印机验收。

## 实现边界

移动端实时预览沿用 React Native 系统字体近似显示，正式 PDF 嵌入现有 Archivo 字体。省彩墨 PDF 的正文、价格和分割线使用 DeviceGray 黑色；Logo 保留原图。实际耗墨量仍取决于打印机与驱动设置。

本次没有变更售价、促销计算、门店数据、打印份数或默认拼版方式；新增请求风格需要移动端与后端配套发布。

## 验证

- 移动端 TypeScript、任务文件 ESLint、海报逻辑与队列测试、中英文文案键检查通过。
- 后端 `PromoPosterTests` 45/45 通过，含三种风格 × 四种促销 × 四种纸张的尺寸检查；补充省彩墨字符串解析、Logo 开关、无原价、混搭条件、A7 大金额及长货号边界回归。
- 使用实际后端渲染器重新生成 16 页和 A6 拼版 PDF，并人工检查四类促销及最小 A7 的价格、优惠、日期和货号位置。
- iOS 原生预览使用隔离测试入口加载实际组件，覆盖 375px 屏幕、320px 海报宽度、长标题、大金额、99 件多件价与 Logo 开关；这不等同于线上登录和打印全流程验收。
- 独立代码审查后已修正 EACH 与分割线重叠、混搭条件遗漏和长文本宽度问题。第二路 DeepSeek 审查在当前配置下不可用。

同一组演示商品、Logo 开启的 A6 四拼样张，以长边 1600px 渲染后，彩色像素占比从经典版约 **14.28%** 降至 **0.51%**。统计条件为 RGB 最大最小差大于 30，且最小值小于 230；它只用于对比画面彩色覆盖面积，不能换算为打印机耗墨下降百分比。
