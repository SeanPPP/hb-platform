# 批量货号销量弹窗与单品查询性能计划

**目标：** 商品范围通过弹窗编辑，商品列表独立滚动；点击单品到每日趋势与分店数据可见以 3 秒为验收目标。
**方案：** 沿用 HB 现有后台组件；前台从商品分店日统计读取销量，成交折扣通过独立持久任务生成聚合快照。两条链路解耦。
**约束：** 专用工作区从 `31605942` 创建；当前侧边对话禁止子代理，因此各模块由主代理依次执行。保留日期、分店权限、导出、未知折扣及退货口径。生产部署不属于本次指令。

## 1. 范围弹窗

- 新建 `ProductScopeModal.tsx` 管理粘贴、文件读取、校验和预览；关闭取消草稿与未完成文件读取，确认后才提交父页面。
- `index.tsx` 只保留已确认货号及弹窗入口；查询使用已确认范围。
- 中文与英文文案同步；保留接口提供的上限，图片中的示意数字不覆盖真实限制。

## 2. 列表与布局

- 商品列表固定高度、内部滚动，列表头和检索入口保持可见。
- 保持选中商品、缩略图、货号、名称和总销量；窄屏可正常访问弹窗及图表。
- 折叠过长的分店范围说明，释放首屏空间。

## 3. 数据正确性与性能

- 已复现：生产 API 的 `WhenWritingNull` 省略空价格，客户端必填校验导致 HTTP 200 仍显示请求失败。先建立失败回归再修正可空价格解析，数量等关键字段仍严格校验。
- 生产基线：HB053-XM-001，2025-09-01 至 2025-12-31，全可见分店，API 26846 ms，326 件、122 天、25 家分店；另一个无销量单日样本 4620 ms。
- 同一生产样本从现有 `ProductStoreDailySalesStatistic` 读取，三次数据库耗时 556 / 528 / 526 ms，251 行、326 件、25 家分店；这不是完整页面耗时。
- 前台：实时校验权限及有效分店，验证日期统计完整，从中间表按日、分店读取数量与金额。缺失统计返回未就绪，不能补成零。
- 折扣：新增独立持久快照表，键包含商品、日期、有效分店与源统计版本。快照保存已聚合的每日分店 JSON，单行原子发布状态与结果，避免多表半成品。
- 后台：仅选中的商品触发去重排队；单个全局租约控制并发。沿用现有事实读取口径；失败最多三次并退避，租约过期可恢复，发布前校验源版本和数量金额，旧 worker 用令牌隔离。数量逐日逐店严格相等，金额按生产日统计 decimal(18,4) 精度校验，发布金额沿用日统计。
- 前台不扫描 POSM / HBSales，不在线执行 DDL。新表未安装时仍显示已有销量，明确折扣未启用。SQL 脚本单独交付，生产执行另属发布流程。
- UI：等待折扣时图表只显示总销量，折扣及退货字段显示“—”；后台完成后自动刷新。排队、失败、源统计未就绪都使用明确状态。详细导出等待折扣完整，摘要可单独导出。
- 影响边界：专用页面、契约、服务和新增 worker / 表；既有商品日统计生产链路及其调用方保持不变。图索引的 GetDetailAsync 调用边不完整，使用控制器调用点和定向测试补充核验。

### 性能证据与边界

商品 `HB053-XM-001`，2025-09-01 至 2025-12-31，全可见 58 家分店；结果始终为 326 件、122 天、25 家有统计分店。

| 测量 | 结果 | 时钟与条件 |
| --- | --- | --- |
| 原生产接口 | 26,846 ms | HTTP 请求计时，旧成交扫描路径 |
| 新服务进程直接冷调用 | 4,735 ms | 本机跨网络读取生产日统计，含新进程首次连接与初始化 |
| 新服务按页面顺序先选项/批查，再首次单品 | 1,921 ms | 本机服务调用及序列化，未命中任何折扣快照 |
| 随后两次单品 | 1,875 / 1,875 ms | 同上；实时重新校验统计版本和门店 |
| 序列化结果大小 | 883,278 -> 113,553 字符 | 同一探针；分店零日期改为按需补齐 |

这些时钟不能混用为同比提速倍数。线上“点击到图表和分店可见 <= 3 秒”尚未验收；原始失败及冷启动样本保留。首次折扣计算仍是异步后台任务，不计作已经生成折扣结果。

### 真实折扣对账

- 只读扫描同一商品成交记录约 24 秒：正价 299 件、折扣 27 件、未知 0，合计 326 件。
- 逐日逐店数量全部一致；47 处金额差异由日统计 4 位小数、成交分摊 6 位小数造成，最大 0.00005。
- 生产字段精度已只读核实为 decimal(18,4)；这 47 处差异已用修正后的编译规则离线回放全部通过。真实数量或四位金额差异依然阻止发布，不通过调整成交价格消除差异。
- 原始未通过记录、差异明细、编译回放结果分别保存在任务 outputs 目录，生产快照表尚未写入。
